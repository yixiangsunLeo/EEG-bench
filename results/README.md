## reference/ — numbers from the paper (not ours)

Transcribed from EEG-FM-Compass (arXiv:2601.17883v3) Table 2 using the PDF text layer
(`docs/papers/2601.17883v3_EEG-FM-Compass.pdf`, page 18):

| file | block |
|:---|:---|

Conventions: values in %, metric per paper §3.4 (BCA for classification; MI datasets also report Acc/κ in
supplementary Tables 16–21, P300 also AUC in Tables 22–25). `_std` over 3 seeds; empty for Traditional ML
(deterministic) and for BrainOmni on CHB-MIT (excluded: no bipolar support). `pretraining_leakage` lists
datasets marked ‡ (used in that FM's pre-training). CHB-MIT / TUAB columns are outside this project's
scope and kept only for completeness.

Known discrepancy: a screenshot of Table 2 circulated on 2026-09-13 showed EEGNet/BNCI2014001 std as 0.27;
the v3 PDF text says 0.57 — the PDF value is used here.
